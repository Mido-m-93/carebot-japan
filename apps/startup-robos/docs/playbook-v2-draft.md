# Small Digital Business Playbook v2 — アップグレード提案

> Jin レビュー後に Notion へ反映する。構造変更は社外参照されるため反映前に Jin 確認必須。

## 背景

現行 Playbook は「ビジネスの始め方」が中心で、以下の弱点がある:
1. 収益レンジ表示のみで「$500/mo に何時間かかるか」が不明
2. Experiments の合否基準が曖昧
3. Co-op 既存クライアント網を使う受注導線が未定義
4. 週次更新が外部トレンドのみで内部実績が反映されていない

## アップグレード 1: ユニットエコノミクス欄

各プレイブックに以下の表を追加:

| 指標 | 値 |
|------|------|
| 初期投資 | $0 (GitHub Pages + 無料ツール) |
| 時間単価換算 | $5-15/hr（到達後） |
| $500/mo 到達までの目安 | 12-20 週 |
| プラットフォーム手数料 | Gumroad 10%, AdSense 32%, Amazon 1-10% |
| 実効収入（手数料控除後） | $450-495/mo @ $500 名目 |

### 適用方法
- Affiliate/SEO: 検索トラフィック × CTR × コンバージョン率 × 報酬単価で逆算
- Digital Products: 販売数 × 単価 × (1 - 手数料率) で月収を計算
- Games + Ads: PV × CPM / 1000 で広告収入を推定

## アップグレード 2: 需要検証ゲート

各プレイブックに「最初の $1 を稼ぐまでのステップ」を明示:

### ゲート構造
```
Week 1-2: 仮説設定
  → 「誰の、何の問題を、どう解決するか」を1文で定義
  → 競合 3 件を調査し差別化ポイントを明示

Week 3-4: MVP デプロイ + トラフィック獲得
  → 最小限のコンテンツ/プロダクトを公開
  → SNS or SEO で 100 ユニークビジター獲得

Week 5-6: 収益化テスト
  → 最初の $1 の発生を確認
  ✅ PASS: $1 以上 → 継続・スケール計画へ
  ❌ FAIL: $0 → 仮説を変更して Week 1 に戻る or 撤退
```

### 撤退基準
- 3 サイクル（18 週）で $1 未達 → 撤退推奨
- ただし Co-op B2B チャネル経由の案件は別評価（アップグレード 3 参照）

## アップグレード 3: Co-op 共同受注チャネル

PDF にある「B2B via Co-op wrapper」を個人プレイブック任せにせず、
Robo Co-op の既存クライアント網を使う受注導線として明文化する。

### 導線設計
```
個人スキル → Co-op 案件マッチング → チーム受注 → 分配

例:
- 翻訳: Co-op が企業翻訳案件を受注 → 難民チームに分配（$15-25/hr）
- RPA/データ入力: Co-op がバックオフィス案件を受注 → 分配（$10-20/hr）
- VA (Virtual Assistant): Co-op が海外企業 VA 案件を受注 → 分配（$8-15/hr）
```

### 個人起業 vs Co-op B2B の比較
| 項目 | 個人起業 | Co-op B2B |
|------|----------|-----------|
| 収益化までの期間 | 12-20 週 | 2-4 週（既存案件マッチ時） |
| 必要スキル | SEO, マーケ, プロダクト開発 | 業務遂行スキルのみ |
| 収益の安定性 | 不安定（トラフィック依存） | 安定（契約ベース） |
| 単価 | $5-15/hr（到達後） | $8-25/hr（案件依存） |
| スケール性 | 高い（デジタル資産蓄積） | 低い（時間売り） |

### 推奨: ハイブリッドアプローチ
短期（~6ヶ月）: Co-op B2B で安定収入を確保しながら
中長期: 個人デジタルビジネスを並行構築

## アップグレード 4: 実績フィードバックループ

StartupRobos の `agent_runs` / startup 実績データから
「どのプレイブックが実際に収益化したか」を週次更新に反映する。

### データソース
- `agent_runs` テーブル: 各ビジネスタイプの活動量（API コスト含む）
- `experiments` テーブル: 仮説の成功/失敗率
- `startups` テーブル: アクティブ/停止の推移

### 週次更新に追加する欄
```markdown
## 今週の実績（自動集計）
- affiliate_seo: 3 実験実行, 1 成功, API コスト $0.12
- digital_product: 2 実験実行, 0 成功, API コスト $0.08
- game_ads: 1 実験実行, 1 成功, API コスト $0.05

## 累計パフォーマンス
- 最も成功率が高いプレイブック: affiliate_seo (67%)
- 最もコスト効率が良いプレイブック: game_ads ($0.05/実験)
```

### 実装方針
- CEO heartbeat レポートに「プレイブック実績サマリ」セクションを追加
- ダッシュボードの Activity ページで可視化
- Notion Playbook ページには「最新実績は Mission Control ダッシュボードを参照」のリンクを追加
  （Notion に自動書き込みはしない — API レート制限のため）
