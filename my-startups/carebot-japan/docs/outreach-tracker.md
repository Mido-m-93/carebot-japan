# CareBot Japan — Outreach Tracker

Tracks founder-led outreach progress against the list in `outreach-targets.md`, using the
templates in `outreach-templates.md`. Update the **Status** and **Date Sent** columns as you go —
nothing here is automated.

**Status values:** `not contacted` → `sent` → `replied` → `call booked` / `declined` / `no response`

**Follow-up rule:** if `sent` and no reply after 5-7 days, send the follow-up template and move
status to `follow-up sent`.
